# Git в VS Code: IDE или терминал

VS Code удобен для просмотра изменённых файлов, diff и истории коммитов. Расширение GitLens показывает автора строк, ветки и связанные коммиты прямо в редакторе.

Для простых операций — stage, commit, push и переключения веток — достаточно панели Source Control. Rebase, cherry-pick, настройку нескольких remote и разрешение сложных конфликтов удобнее контролировать через терминал, где видны точные команды Git.
