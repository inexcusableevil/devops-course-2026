# Мой пет проект

Идея: Telegram-бот для учёта личных расходов.

Стек: Python, SQLite, Telegram Bot API.

Цель: освоить проектирование небольшого сервиса, работу с API и хранением данных.

## План реализации

1. Спроектировать модель доходов и расходов в SQLite.
2. Реализовать команды добавления операции и просмотра баланса.
3. Добавить сводку расходов по категориям за месяц.
