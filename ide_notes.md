# Git в VS Code и терминале

## Удобно в VS Code

1. Наглядно просматривать изменения файла в diff-редакторе.
2. Видеть список изменённых и неотслеживаемых файлов в панели Source Control.
3. Открывать историю и blame через GitLens.

## Удобнее в терминале

Создавать и анализировать ветки, выполнять rebase, cherry-pick и другие сложные операции, когда нужны точные команды и полный контроль.

Для простых операций — stage, commit, push и переключения веток — достаточно панели Source Control.
