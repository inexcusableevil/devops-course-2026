# Git и SVN

## Почему ветвление в Git дешёвое, а в SVN дорогое

В Git ветка - это лёгкая ссылка на коммит, поэтому её создание почти не требует места и выполняется локально. В SVN ветвление обычно связано с копированием дерева на центральном сервере, поэтому операция заметнее зависит от сети и размера проекта.

## Можно ли сделать коммит в SVN без интернета

Нет. SVN хранит центральную историю на сервере, и коммит должен быть принят этим сервером. Офлайн можно подготовить изменения, но зафиксировать их в общей истории нельзя.

## Когда SVN может быть предпочтительнее Git

SVN может быть оправдан при сопровождении существующей централизованной инфраструктуры, если процесс и инструменты организации уже построены вокруг него, либо когда требуется простая модель единого сервера и нет потребности в распределённой работе.
